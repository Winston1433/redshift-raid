# 🧱 Tetris 俄羅斯方塊

用純 **HTML + CSS + JavaScript** 寫的俄羅斯方塊小遊戲，不需任何框架或安裝，打開瀏覽器就能玩！

## 🎮 玩法（超簡單）

1. 點一下藍色的 **「▶ 開始遊戲」** 按鈕
2. 移動與旋轉下落中的方塊，讓它們在底部**排滿一整行**就能消掉得分
3. **堆到最頂端就輸了**，看你能撐幾分！

### 操作方式

| 動作 | 電腦鍵盤 | 手機 |
| --- | --- | --- |
| 左右移動 | `←` `→` | 螢幕按鈕或左右滑動 |
| 旋轉 | `↑` | 螢幕 `↻` 按鈕或點一下畫面 |
| 加速落下 | `↓` | 螢幕 `⬇` 按鈕 |
| 直接落底 | `空白鍵` | 螢幕 `⤓ 落底` 按鈕 |

## 🏆 計分規則

- 消 1 行 = 100 分 × 等級
- 消 4 行（Tetris!）= 800 分 × 等級
- 每消 10 行升一級，方塊掉落速度會越來越快
- 最高分自動存在瀏覽器裡（localStorage）
