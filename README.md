# 🐍 Snake Game

用純 **HTML + CSS + JavaScript** 寫的經典貪吃蛇小遊戲，不需任何框架或安裝，打開瀏覽器就能玩！

## 🎮 玩法（超簡單）

1. 點一下綠色的 **「▶ 開始遊戲」** 按鈕
2. 用螢幕上的方向按鈕（或電腦鍵盤 `↑ ↓ ← →` / `W A S D`）控制蛇
3. 吃到紅色小球 +10 分，**不要撞到牆壁和自己**！

## 🚀 本地執行

直接用瀏覽器打開 `index.html` 即可，或在本機啟動一個簡單的伺服器：

```bash
npx serve .
```

## 🌐 GitHub Pages

到 GitHub 儲存庫 → **Settings → Pages → Source 選 `main` 分支 / root**，
之後就能透過網址直接線上玩。

## 📁 專案結構

```
snake-game/
```
